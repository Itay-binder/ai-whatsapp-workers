# עובדי AI בווצאפ

עובד AI עם תפקיד, שמחובר לווצאפ, עונה רק לכם ורואה רק את התיקיות שהגדרתם.

- **ההדרכה המלאה (דף אינטראקטיבי):** https://ai-whatsapp-workers.vercel.app
- **ערכת ההתחלה:** [`starter/`](starter/) כוללת שרת Baileys, מוח Claude (Agent SDK), תבנית תפקיד, תמלול מקומי וסקיל לקליטת עובד חדש. הוראות התקנה ב-[`starter/README.md`](starter/README.md).
- **קוד הדף:** [`site/`](site/)

> Baileys היא ספרייה לא רשמית. היא מתאימה להתכתבות יומיומית איתכם ועם הצוות, ולא מתאימה לדיוורים או לשליחה המונית, כי יש סיכון לחסימת המספר.
